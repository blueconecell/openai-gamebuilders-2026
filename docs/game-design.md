# OVERFLOW: FAR SPACE — 메인 게임 기획서 (v0.3)

> OpenAI GameBuilders 2026 본선 / 주제: **Go Limitless, Surprise Me**

## 1. 한 줄 피치

> **무한한 우주를 항해하며 강적의 부품을 빼앗아, 한계를 넘는 우주선을 만드는 탑뷰 로그라이트.**

적이 대량으로 몰려오는 뱀서라이크가 아니다. 고요한 우주를 이동하고, 소수의 강한 적을 해체해 얻은 부품으로 우주선을 계속 확장한다.

## 2. 핵심 경험

- 공백 공간을 탐험하며 미지 신호를 발견한다.
- 미지 구역에 참여하거나 지나갈지 선택한다.
- 짧고 어려운 전투에서 적의 핵심 부품을 노린다.
- 회수한 부품을 간단한 소켓 방식으로 장착한다.
- 부품의 연결 순서로 화력을 배수 증폭시킨다.
- 충분히 성장한 뒤 메인 퀘스트 보스를 격파한다.

```text
공백 탐색
→ 미지 신호 발견
→ 참여 또는 통과
→ 짧은 조우
→ 장착 또는 분해
→ 공백 상점에서 정비
→ 메인 보스
→ 다음 항로
```

## 3. 공간 구조

### 3.1 공백 공간

탐색, 휴식, 조립과 상점 이용을 담당하는 안전 공간.

- 적이 없을 때 3초간 정지하면 자동 클로킹
- 클로킹 중 무적 및 안전 저장
- 일시정지 또는 종료 시 즉시 클로킹 상태로 저장
- 이동 거리가 쌓이면 주변에 미지 신호가 생성
- 먼 거리는 기본 워프로 이동
- 클로킹 상태에서 상점과 우주선 정비 이용 가능

공백 이동은 다음 의미 있는 선택까지 20~30초를 넘기지 않는다.

### 3.2 미지 구역

공백 공간을 이동하다 발견하는 선택형 랜덤 이벤트.

- 신호 접근 시 `진입` 또는 `지나가기` 선택
- 진입 전 위험도와 보상 등급만 표시
- 정예 적, 폐선, 구조 요청, 상인, 이상 현상 등이 랜덤 발생
- 일반 전투는 30~90초 안에 종료
- 성공하면 부품을 회수해 장착하거나 분해

미지 신호는 실제 이동 거리 또는 탐색 게이지로 생성해 제자리 반복 파밍을 막는다.

### 3.3 메인 퀘스트 구역

현재 항로의 진행을 검증하는 보스 전투 공간.

- 강력한 모듈형 보스 우주선 출현
- 보스 부품 구조에 따라 공격 패턴 변화
- 보스전은 60~120초를 목표로 함
- 전투 중 클로킹과 워프 사용 불가
- 처치 시 핵심 부품과 다음 LIMIT 신호 좌표 획득

## 4. 짧은 호흡의 로그라이트

전체 우주 탐험을 3분마다 초기화하지 않는다. 대신 **각 조우는 짧고, 우주선의 상태는 탐험 동안 이어진다.**

- 미지 구역 조우: 30~90초
- 메인 보스 조우: 60~120초
- 부품 선택과 정비: 10~20초
- 본선 시연: 미지 구역 1회 + 보스 1회, 약 3분
- 코어가 파괴되면 현재 탐험 종료

짧은 전투를 여러 번 통과하며 하나의 우주선을 완성하는 구조다.

## 5. 전투

적은 한 번에 1~3기만 등장하지만 각각 강하다.

- 공격은 자동
- 플레이어는 이동과 적 부품 집중 조준을 담당
- 적 무기 파괴: 적 화력 감소
- 적 추진기 파괴: 이동과 도주 제한
- 적 연결부 파괴: 연결된 외부 부품 분리
- 적 코어 파괴: 즉시 승리
- 온전하게 남은 부품만 좋은 상태로 회수 가능

적 코어는 시작 시 장갑 또는 연결 부품에 가려져 직접 공격할 수 없다. 보호 부품을 먼저 제거해 코어를 노출해야 한다.

난이도는 높은 체력보다 공격 예고, 이동 경로, 부품 구조와 파괴 순서에서 만든다.

### 폭파 조건

- 플레이어 우주선에는 핵심 코어가 정확히 1개 존재한다.
- 외부 부품은 개별적으로 파괴되거나 떨어져 나간다.
- 핵심 코어가 파괴되는 순간 우주선 전체가 폭파되고 탐험이 종료된다.
- 장갑과 연결 구조로 코어를 보호하는 배치가 중요하다.
- 코어가 위험할 때 명확한 경고와 짧은 피격 유예를 제공한다.

## 6. 모바일 우선 부품 배치

자유로운 픽셀 단위 배치 대신 **마그네틱 소켓 방식**을 사용한다.

### 장착

1. 획득한 부품을 탭한다.
2. 장착 가능한 소켓만 우주선 위에 표시된다.
3. 원하는 소켓을 탭하면 부품이 자동으로 회전하고 결합된다.

드래그도 지원하지만 필수 조작은 아니다. 한 손으로 `부품 탭 → 소켓 탭`만 하면 장착이 끝난다.

MVP에서는 자유 그래프 대신 `코어 → 증강 소켓 → 무기`로 이어지는 고정 레일을 사용한다. 부품을 선택하면 적용될 무기와 계산 결과를 동시에 강조한다.

### 재배치

- 장착된 부품을 탭하고 다른 소켓을 탭하면 이동
- 두 부품을 차례로 탭하면 위치 교환
- 이동 전 예상 화력과 질량 변화를 미리 표시
- 장착 직후 한 번의 되돌리기 제공
- 조립은 전투가 끝난 안전 구간에서만 진행

자유도보다 빠른 이해와 즉각적인 결과를 우선한다.

## 7. 증강과 배수 도파민

코어에서 무기까지 연결된 부품의 순서가 공격력을 결정한다.

```text
코어 2 → +3 → ×2 → 레이저 = 화력 10
코어 2 → ×2 → +3 → 레이저 = 화력 7
```

- 연산자는 `+`, `×`, 분열처럼 직관적인 기능만 사용
- 장착 전 예상 결과 표시
- 재배치 순간 숫자, 탄환 크기, 발사 수와 사운드가 함께 변화
- 일정 배수를 넘으면 짧은 `OVERFLOW` 상태 발동
- OVERFLOW 중 공격 효과와 숫자가 한 단계 폭발적으로 증가

핵심 도파민은 희귀 부품을 얻는 순간뿐 아니라 **같은 부품을 재배치해 화력이 자릿수 단위로 상승하는 순간**이다.

## 8. 과적과 부품 분해

부품 수에 하드 제한을 두지 않지만, 많이 붙일수록 질량 패널티가 커진다.

화면에는 `안정 / 과적`이 구분된 질량 게이지를 표시한다. 부품을 장착하기 전에 화력 상승과 이동 속도 하락을 함께 보여 준다.

- 질량 증가: 이동과 회전 속도 감소
- 크기 증가: 피격 면적 증가
- 증폭기 증가: 발열과 재사용 대기시간 증가
- 긴 연결 구조: 연결부 파괴 시 다수 부품 손실 위험

사용하지 않는 부품을 버리게 만들지 않고 `스크랩`으로 분해한다.

- 일반 부품 분해: 소량의 스크랩
- 희귀 부품 분해: 더 많은 스크랩
- 손상 부품 분해: 상태에 따라 획득량 감소
- 분해는 공백 공간 또는 전투 종료 후 가능
- 회수한 미장착 부품은 최대 3개까지만 임시 보관

플레이어는 매번 `장착해서 강해질지`, `과적을 피하고 분해할지` 선택한다.

## 9. 공백 상점과 워프 배송

클로킹 상태에서 공백 상점을 이용해 스크랩을 소비한다.

### 판매 항목

- 수리 키트
- 기본 장갑과 연결 프레임
- 무기 또는 증강 부품
- 리롤권
- 다음 미지 신호의 정보

구매한 물품은 즉시 인벤토리에 들어가지 않는다.

> 구매 완료 후 배송 캡슐이 워프해 플레이어 근처에 도착한다.

배송 캡슐은 도착 즉시 자동으로 열린다. 구매 행위 자체를 우주 안에서 보이는 짧은 보상 연출로 만들되 별도의 이동 시간을 요구하지 않는다.

## 10. 목표와 실패

### 단기 목표

- 미지 신호를 조사하고 필요한 부품 확보
- 현재 조우에서 코어를 보호하며 적 코어 파괴

### 중기 목표

- 미지 구역을 통해 우주선 강화
- 현재 항로의 메인 보스 격파
- 다음 LIMIT 신호 좌표 획득

### 장기 목표

무한한 우주에 흩어진 LIMIT 신호를 추적해 신호의 근원에 도달한다.

### 실패 후 남는 것

- 발견한 부품 도감
- 새로운 시작 코어와 부품 계열
- 블랙박스로 보존한 부품 1개 또는 연구 데이터

## 11. 본선 MVP

```text
클로킹 상태에서 시작
→ 이동해 미지 신호 발견
→ 참여 선택
→ 정예 적 부품 해체
→ 부품 장착 또는 분해
→ 공백 상점에서 구매
→ 배송 캡슐 워프
→ 메인 보스 전투
→ OVERFLOW 승리
```

### 필수 구현

- 탑뷰 이동과 자동 공격
- 적 부품 집중 조준과 부분 파괴
- 보호 부품 제거 후 노출되는 핵심 코어
- 고정 레일 기반 마그네틱 소켓 4~6개
- `+`, `×` 기반 배수와 보장된 OVERFLOW 조합
- 과적 패널티와 부품 분해
- 고정된 미지 조우 1개와 보스 1개
- 클로킹, 워프, 상품 2개의 상점과 배송 연출 1회
- 보스 1종과 OVERFLOW 연출

### MVP 이후 확장

- 절차적으로 생성되는 우주와 미지 이벤트
- 실제 저장 및 재접속
- 분열을 포함한 추가 연산자
- 발열과 재사용 대기시간
- 범용 상점, 리롤과 장기 경제
- 장기 메타 진행

## 12. 핵심 설계 원칙

1. 전투는 짧게, 탐험과 우주선은 이어지게 한다.
2. 적의 수보다 부품 파괴 순서로 난이도를 만든다.
3. 모바일에서는 자유 배치보다 두 번의 탭으로 조립한다.
4. 부품 증가는 힘이면서 동시에 질량과 위험이다.
5. 필요 없는 부품도 분해와 상점으로 다음 선택에 기여한다.
6. 코어 하나를 지키는 것이 모든 전투의 명확한 생존 목표다.
