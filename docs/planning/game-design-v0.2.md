# 무한항로 — 게임 기획 보강안 (v0.2)

> OpenAI GameBuilders 2026 본선 / 주제: **Go Limitless, Surprise Me**

## 1. 현재 방향

작은 코어 우주선으로 무한한 우주를 이동하고, 소수의 강적을 해체해 얻은 부품으로 우주선을 계속 확장하는 탑뷰 로그라이트.

> **부품의 성능보다 연결 순서가 중요한, 짧은 호흡의 우주선 해체 로그라이트.**

### 핵심 특징

- 《Captain Forever》처럼 적의 부품을 파괴하고 회수해 즉시 조립한다.
- 적이 대량으로 몰려오지 않는다. 한 번에 1~3기의 강한 적과 싸운다.
- 공격은 자동이며, 플레이어는 이동과 적 부품 집중 조준을 담당한다.
- 부품 연결 순서에 따라 화력이 배수로 증가한다.
- 공백 공간에서는 언제든 클로킹하고 안전하게 게임을 종료할 수 있다.

## 2. 현재 기획에서 보강해야 할 점

### 2.1 무한 탐험과 짧은 로그라이크의 충돌

무한한 우주를 탐험하는 게임은 목표가 흐려지고 플레이 시간이 길어지기 쉽다. 반대로 모든 진행을 3분짜리 런으로 초기화하면 탐험과 우주선 조립의 애착이 약해진다.

따라서 **전투는 짧게, 탐험은 이어지게** 구성한다.

- 미지 구역 조우: 30~90초
- 메인 퀘스트 보스: 60~120초
- 부품 선택과 재배치: 10~20초
- 미지 구역 1회와 보스 1회를 합친 본선 시연: 약 3분
- 여러 조우를 통과한 우주선 상태는 탐험이 끝날 때까지 유지

즉, 3분은 전체 게임의 길이가 아니라 **하나의 완결된 항해 단위**다.

### 2.2 세 구역을 반복 가능한 루프로 연결

현재 세 구역은 역할은 분명하지만 서로를 이어 주는 진행 규칙이 부족하다.

```text
공백 공간 이동 및 신호 탐색
→ 미지 구역 참여 여부 선택
→ 짧은 전투 또는 랜덤 이벤트
→ 부품 획득 및 조립
→ 메인 퀘스트 구역으로 워프
→ 보스 격파
→ 다음 항로 선택 또는 안전 귀환
```

공백 공간에서 제자리 왕복만 해도 미지 구역이 계속 생성되면 반복 파밍이 가능하다. 미지 신호는 `이동 거리` 또는 `탐색 게이지`가 충족됐을 때 생성한다.

### 2.3 소수 전투의 개입감

적이 적은 게임에서 자동 공격만 사용하면 전투가 관람처럼 느껴질 수 있다. 플레이어에게 다음 한 가지 전술 결정을 추가한다.

> **적 우주선의 어떤 부품을 먼저 파괴할지 선택한다.**

- 무기 파괴: 적의 화력 감소
- 추진기 파괴: 이동과 도주 제한
- 연결부 파괴: 바깥쪽 부품을 한꺼번에 분리
- 코어 파괴: 전투 즉시 종료
- 온전하게 남긴 부품만 전리품으로 회수 가능

적의 체력만 높이는 방식은 피한다. 어려움은 부품 구조, 공격 예고, 이동 경로와 약점 선택에서 만든다.

### 2.4 조립과 연산 규칙의 직관성

복잡한 수식 퍼즐은 첫 10초 이해를 방해한다. 연산자는 `+`, `×`, 분열 정도로 제한하고 에너지 흐름을 선과 색으로 보여 준다.

```text
코어 2 → +3 → ×2 → 레이저 = 화력 10
코어 2 → ×2 → +3 → 레이저 = 화력 7
```

- 코어에서 무기 방향으로 계산한다.
- 부품 장착 전에 예상 화력 변화를 표시한다.
- 결과는 우주선 위와 발사 효과에서 즉시 확인한다.
- 숫자를 읽지 않아도 탄환 크기, 개수, 색상과 사운드로 강화를 느끼게 한다.

## 3. 공간 구조

### 3.1 공백 공간

휴식, 이동, 탐색과 우주선 정비를 담당하는 기본 공간.

- 적이 없는 상태에서 3초간 정지하면 자동 클로킹
- 클로킹 중 무적 및 안전 저장
- 일시정지 또는 게임 종료 시 즉시 클로킹 상태로 저장
- 재접속 시 같은 위치의 클로킹 상태에서 시작
- 이동 거리가 쌓이면 주변에 미지 신호 생성
- 먼 거리는 기본 워프로 이동

공백 공간은 길게 비워 두지 않는다. 다음 의미 있는 선택까지 20~30초를 넘기지 않는 것을 목표로 한다.

### 3.2 미지 구역

플레이어가 선택해서 참여하는 짧은 랜덤 이벤트 공간.

- 신호의 위험도와 보상 등급만 미리 표시
- 정확한 사건은 진입 후 공개
- 참여하지 않고 지나갈 수 있음
- 전투, 구조, 폐선, 상인, 이상 현상 등으로 구성
- 성공 시 부품 3개 중 하나를 선택하거나 회수 부품을 조립

랜덤은 완전히 통제 불가능하게 두지 않는다. 리롤, 신호 무시, 부품 분해 중 최소 두 가지 개입 수단을 제공한다.

### 3.3 메인 퀘스트 구역

탐험 진행을 검증하는 보스 전투 공간.

- 강력한 모듈형 보스 우주선 출현
- 보스의 부품 구조에 따라 공격 패턴 변화
- 전투 중 클로킹과 워프 불가
- 처치 시 핵심 부품과 다음 LIMIT 신호 좌표 획득
- 다음 항로로 진행하거나 귀환해 성과를 저장할 수 있음

## 4. 짧은 전투 구조

### 일반 조우: 30~90초

- 적 1~3기 등장
- 이동하며 공격을 회피
- 탭 또는 클릭으로 파괴할 적 부품 지정
- 전투 종료 후 안전한 조립 시간 제공

### 보스 조우: 60~120초

- 보스는 2~3개의 핵심 부품군으로 구성
- 핵심 부품을 파괴할 때마다 패턴이 눈에 띄게 변화
- 단순한 체력 감소보다 우주선이 실제로 해체되는 모습을 강조

### 조작

| 행동 | 모바일 | PC |
|---|---|---|
| 이동 | 화면 드래그 | WASD / 방향키 |
| 집중 조준 | 적 부품 탭 | 마우스 클릭 |
| 부품 조립 | 전투 후 드래그 | 전투 후 드래그 |
| 공격 | 자동 | 자동 |
| 워프·클로킹 | 자동 또는 단일 버튼 | 자동 또는 단일 버튼 |

전투 중 자유 조립은 모바일 피로도를 높이므로 기본적으로 금지한다.

## 5. 증강과 배수 도파민

### 핵심 도파민 순간

좋은 부품을 얻는 순간보다 **배치 순서를 바꿔 화력이 갑자기 폭발하는 순간**을 핵심으로 삼는다.

```text
화력 320 → 부품 재배치 → 1,280 → OVERFLOW
```

### OVERFLOW 상태

연결된 부품이 일정 배수를 넘으면 짧은 오버플로우 상태가 발동한다.

- 공격 크기와 발사 수 증가
- 우주선 에너지 색상 변화
- 숫자 자릿수 상승 연출
- 짧고 강한 사운드와 화면 반응
- 조건을 달성한 동안만 한계가 해제됨

### 강함의 비용

배수만 높이는 것이 항상 정답이 되지 않도록 물리적인 대가를 둔다.

- 부품 증가 → 질량과 피격 면적 증가
- 증폭기 증가 → 발열 증가
- 긴 연결 구조 → 연결부 파괴에 취약
- 무기 집중 → 추진과 방어 능력 부족

무제한 곱연산은 밸런스와 가독성을 무너뜨릴 수 있으므로, 평상시 배수에는 상한을 두고 OVERFLOW 상태에서만 잠시 상한을 해제한다.

## 6. 목표와 로그라이크 구조

### 단기 목표

- 현재 미지 신호의 사건 해결
- 필요한 부품을 온전하게 회수
- 메인 퀘스트 보스 격파

### 중기 목표

- 한 항로에서 보스 3기 격파
- 다음 항성계로 이동할 좌표 확보
- 현재 성과를 들고 귀환할지 더 진행할지 선택

### 장기 목표

우주 곳곳에서 감지되는 `LIMIT 신호`를 추적해 신호의 근원에 도달한다.

### 실패와 잔존 성장

- 코어 파괴 시 현재 탐험 종료
- 부품 도감과 발견 정보 유지
- 새로운 시작 코어와 부품 계열 해금
- 블랙박스를 통해 부품 하나 또는 연구 자원 일부 계승

실패 후 유지되는 요소는 다음 플레이의 선택지를 늘리되 기본 공격력을 과도하게 올리지는 않는다.

## 7. 본선용 MVP

### 시연 루프

```text
공백 공간과 클로킹 확인
→ 이동해 미지 신호 발견
→ 정예 적 1기와 전투
→ 부품 3택 및 재배치
→ 워프
→ 보스 해체
→ OVERFLOW 승리 연출
```

목표 플레이 시간은 약 3분이다.

### 필수 구현

- 탑뷰 이동과 자동 공격
- 적 부품 집중 조준 및 부분 파괴
- 부품 회수와 드래그 조립
- `+`, `×`, 분열 기반 연결 효과
- 공백·미지·메인 퀘스트 3구역 전환
- 클로킹과 워프
- 보스 1종과 OVERFLOW 연출

### 후순위

- 무한 절차 생성
- 다수의 이벤트와 보스
- 상인과 경제 시스템
- 온라인 기능과 경쟁 요소
- 복잡한 물리 시뮬레이션

## 8. 주요 위험과 대응

| 위험 | 대응 |
|---|---|
| 공백 이동이 지루함 | 다음 신호까지 20~30초 이내, 먼 거리는 워프 |
| 제자리 왕복으로 이벤트 파밍 | 실제 이동 거리 또는 탐색 게이지 사용 |
| 자동 공격으로 전투가 수동적임 | 적 부품 집중 조준과 회수 품질 연결 |
| 연산 규칙이 복잡함 | `+`, `×`, 분열만 사용하고 결과 미리 보기 제공 |
| 부품 손실 후 회복 불가능 | 전투 후 최소 수리 또는 기본 프레임 보장 |
| 큰 우주선만 항상 유리함 | 질량, 회전 속도, 피격 면적, 발열 비용 적용 |
| 무한 탐험으로 목표가 흐려짐 | 단기 신호, 중기 항로, 장기 LIMIT 신호를 항상 표시 |
| 유사작과 차별화가 약함 | 연결 순서, 소수 적 해체, 3분 항해를 핵심 문장으로 고정 |

## 9. 아직 결정해야 할 사항

1. 우주선 조립을 자유 그리드로 할지 제한된 연결 포인트로 할지
2. 탐험 종료 시 우주선을 완전히 초기화할지 일부 보존할지
3. OVERFLOW를 시간제 폭발 상태로 할지 보스전 전용 상태로 할지
4. 공백 공간의 이동을 직접 비행 중심으로 할지 목적지 선택 중심으로 할지
5. 본선 빌드를 세로 화면으로 유지할지 가로 화면으로 변경할지

## 10. 현재 우선순위

1. 3분 시연 루프 확정
2. 소수 적의 부품 집중 조준 전투 검증
3. 부품 배치에 따른 배수 폭발 시각화
4. 공백·미지·메인 구역의 전환 구현
5. 장기 메타 진행 확장
